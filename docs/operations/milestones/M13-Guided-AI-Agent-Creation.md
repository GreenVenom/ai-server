# M13 Guided AI Agent Creation

## Objective

Create specialized agents safely through approved templates, policies, and validated configuration.

## Scope

Included:

- Guided UI and CLI workflows for agent definitions.
- Reusable templates with validated model, retrieval, and MCP selections.
- Preview and test workflow before activation.
- Versioning, ownership, change history, and rollback.

Excluded:

- Bypassing M11 lifecycle validation or M12 MCP governance.

## Success Criteria

- A proposed agent is previewed and tested before it can be activated.
- Templates prevent unapproved model, retrieval, or MCP selections.
- Definition ownership, history, and rollback are available to operators.

## Exit Criteria

M13 is complete when guided creation, policy validation, preview/testing, version history, rollback, and documentation are verified.
