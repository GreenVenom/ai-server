# M15 v2.0.0 Hardening and Release

## Objective

Validate the complete platform and publish the v2.0.0 release.

## Scope

Included:

- End-to-end acceptance testing for models, UI, agents, MCP governance, and file-update workflows.
- Security review of authentication, permissions, exposed interfaces, secrets handling, and recovery paths.
- Updated architecture, operations, ADRs, runbooks, migration notes, and user documentation.
- Final release verification, version bump, annotated Git tag, and v2.0.0 release notes.

Excluded:

- Declaring v2.0.0 complete before all M09–M14 controls are proven end-to-end.

## Success Criteria

- Acceptance tests demonstrate the secure workflow: model management → UI → agents → governed MCP → approved file automation.
- Security and recovery reviews have no unresolved release-blocking findings.
- Release documentation, versioning, tag, and verification evidence are complete.

## Exit Criteria

M15 is complete only when the v2.0.0 release has passed acceptance and security review, the repository documentation is current, and the verified release is tagged.
