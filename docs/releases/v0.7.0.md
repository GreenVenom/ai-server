# v0.7.0 Release Notes

## Summary

v0.7.0 completes M07 by cutting the `personal-knowledge` Obsidian retrieval workload over to the independently rebuilt V2 index.

## Highlights

- `obsidian_chunks_v2` is the live Qdrant collection, with manifests under `data/obsidian/manifests-v2`.
- The production indexer, scheduled LaunchAgent, MCP adapter, and OpenClaw Obsidian plugin target V2.
- Reconciliation now compares manifest chunk IDs with Qdrant point IDs instead of treating every mirrored Markdown file as indexable.
- The accepted V2 index contains 39 manifest documents and 265 Qdrant chunks.

## Known limitations

The V1 collection and original manifest remain retained as read-only rollback data for at least 30 days after 2026-07-27. The mirror has intentional non-indexable content: discovery exclusions, dynamic templates with invalid YAML frontmatter, and zero-body notes.

## Next steps

M08 will validate backup and restore coverage for the active V2 collection, V2 manifest root, production configuration, and scheduler state. V1 removal requires a separately recorded cleanup decision after the retention period.
